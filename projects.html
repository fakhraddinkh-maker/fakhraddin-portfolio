🧬 Project 1: RNA-seq Bioinformatics Pipeline Development

Reproducible Transcriptomics Workflow

Development of a structured and reproducible RNA-seq analysis workflow for animal transcriptomics studies using R-based bioinformatics approaches.

Workflow Components

  • RNA-seq data organization and preprocessing
  • Quality control and exploratory data analysis
  • Differential expression analysis using DESeq2
  • Gene annotation and biological interpretation
  • GO and KEGG functional enrichment analysis
  • Scientific visualization and reproducible reporting

Computational Skills

  • R Programming
  • Bioconductor Framework
  • DESeq2
  • Functional Genomics Analysis
  • Data Visualization

Status: Bioinformatics workflow development project.

🐔 Project 2: Broiler Breeder RNA-seq Functional Genomics Study

GSE113722 Transcriptomic Analysis

This research project investigates molecular responses associated with feeding conditions in broiler breeder hens using RNA-seq and functional genomics approaches.

Analytical Framework

  • RNA-seq transcriptomic analysis
  • Differential expression analysis using DESeq2
  • Gene annotation
  • GO functional enrichment analysis
  • KEGG pathway analysis
  • GSEA analysis
  • STRING protein interaction network analysis

Status: Manuscript in preparation.

Research results, figures and detailed findings will be released after publication.
